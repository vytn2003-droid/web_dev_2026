Purpose of this page

This page collects a few learning resources I’m using while building my site. I’m also using it as a starter “portfolio” page where I can summarize projects in plain language.

Over time, I want each resource or project to have a short description so visitors know why it matters, not just a list of links.

Project notes

Semantic website (this project)

This site is practice for writing meaningful content and organizing it with semantic HTML. The structure is designed so that headings create a clear outline and each page has an obvious purpose.

Account safety mini-guides

I’m interested in simple, practical guides about security habits like password managers and MFA. I want to write explanations that work for beginners and avoid unnecessary jargon.
