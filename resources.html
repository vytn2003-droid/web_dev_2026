Purpose of This Page

This page gathers some of the online learning materials and tools that have helped me while studying HTML, networking, and cybersecurity. I use it as both a reference page and a space to summarize what I’m learning in a clear and simple way.

Over time, I plan to expand these notes with new articles, tutorials, and short personal takeaways. My goal is to understand *why* each resource matters — not just to bookmark links.

Current Learning Projects

Semantic Website (This Project)

This site was built using only HTML5 to focus on document structure and meaning. It helped me understand how elements like header, main, and footer work together to create an accessible layout. Publishing it through GitHub Pages gave me hands-on experience managing files and organizing a small site.

Account Safety Mini-Guides

I’m writing short, plain-language guides on digital safety habits — including how to use password managers, set up multi-factor authentication, and recognize phishing emails. My focus is on keeping these explanations simple, practical, and helpful for beginners.

Networking and Subnetting Practice

To strengthen my technical foundation, I’m practicing subnetting, IP addressing, and troubleshooting exercises. These activities help me build confidence for future roles in cybersecurity and IT support.

Recommended Learning Resources

Here are a few sites and tools that I find especially helpful:

  • MDN Web Docs – clear documentation on HTML, CSS, and web standards.
  • freeCodeCamp – free tutorials and coding practice projects.
  • CISA.gov – official cybersecurity guidance and safety tips.
  • Coursera – professional certificate programs and online learning paths.
  • GitHub – version control and hosting for web projects.
