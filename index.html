Welcome

This site is a small, three-page project focused on writing meaningful content and structuring it with semantic HTML. I’m keeping the design intentionally plain for now so the structure is easy to read and validate.

My goal is to practice building pages that make sense even without styling. If you skim the headings, you should still understand the purpose of each page and how the information is organized.

What I’m focusing on

Semantic HTML and clear structure

I’m using elements like <header>, <nav>, <main>, <section>, and <article> because they communicate meaning to browsers, assistive technologies, and other developers. This makes the site easier to maintain and more accessible.

Real content first

Instead of filler text, each page has short paragraphs that explain who I am, what I’m learning, and how I’m planning my next steps after graduation. Later, when we add CSS, the pages will already have a strong foundation.

Next steps

In future updates, I plan to add styling, improve navigation patterns, and expand the “Resources” page into a small portfolio. I also want to add a simple contact workflow, but since forms won’t submit on GitHub Pages, I’ll describe that idea in writing instead of building it for this task.
